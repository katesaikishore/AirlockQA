# Roadmap

This is a direction, not a promise. Dates are deliberately absent.

## Now

- Verified Merge: affected-spec selection, deterministic rerun, signed verdicts
- in-toto/DSSE attestations and offline verification
- attach/flake reporter path for existing Playwright suites
- MCP tools for agents
- open-source maintainer program

## Next

- First-class support for more Playwright project layouts and monorepos
- Better flake attribution from request ledgers and traces
- More CI providers beyond GitHub Actions
- Published accuracy numbers from real repositories

## Later

- Team workflows for triage ownership
- Compliance exports mapped to customer controls
- Additional language runtimes once the TypeScript path is solid

## Not planned

- Replacing your test runner
- Generated tests dominating a suite
- Reporting a failure we could not reproduce
