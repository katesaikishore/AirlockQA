## What each method covered

### Hosted QA (umami, fixture control)

Airlock Cloud built and started the public repository at the pinned commit, ran `smoke` and `explore`, saved screenshots,
and produced a signed result. Umami visited one page; it is a narrow smoke/explore pass, not an exhaustive test.

### Live smoke audit (MoneyMatter, ConvoForm, Betterlytics, Hibi)

Headless Chrome loaded the public home page at 1365×900, waited for the network to settle, and checked:

- console errors and uncaught page errors,
- failed responses (HTTP ≥ 400),
- images without an `alt` attribute in the initial DOM,
- horizontal overflow,
- the page title/H1 and internal-link surface.

This is intentionally not a claim about auth flows, destructive actions or security. A clean live smoke audit means the
page loaded without those obvious failures; it is **not** a security certification.

## The MoneyMatter finding

Every public page loads PostHog helper scripts through the same-origin proxy. The proxy returns an nginx 502 page:

```bash
curl -sS -o /dev/null -w '%{http_code}\n' \
  https://moneymatter.app/helper/static/1.428.5/web-vitals-with-attribution.js
# 502
```

The direct PostHog asset is healthy:

```bash
curl -sS -o /dev/null -w '%{http_code}\n' \
  https://eu-assets.i.posthog.com/static/1.428.5/web-vitals-with-attribution.js
# 200
```

The browser sees `text/html` where it expects JavaScript and refuses to execute it. The public issue with the full
reproduction is [#862](https://github.com/letehaha/moneymatter/issues/862). No pull request was opened; this follows the
issue-first rule.

## Umami finding

The hosted run recorded one S3 finding: the home page did not send a `Strict-Transport-Security` header. The report and
screenshot are linked above. One finding is not a risk rating for the whole application.

## Why some entries say “passed”

ConvoForm, Betterlytics and Hibi loaded without console errors, failed responses, missing image alternatives in the
initial DOM, or horizontal overflow. That is a real result for a smoke audit, and it is also a limited one. They were not
built in the hosted sandbox and no authenticated flow was exercised, so the index does not claim more.

## Reproduce

```bash
# Hosted QA against a public commit
airlock qa --repo https://github.com/owner/repo --sha <40-char-sha> --suites smoke,explore --wait

# The same checks in a pull request
# uses: katesaikishore/AirlockQA@v1
```
