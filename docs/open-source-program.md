# Open-source maintainer program

QAFind is MIT-licensed. Maintainers of open-source projects that run Playwright get:

- Verified Merge in **comment-only mode** free, with no required check while you evaluate
- signed verdicts and in-toto/DSSE attestations you can keep
- help reading the first flake report
- no public mention of your project unless you approve it

## How to join

Open an issue using the **Feature request** template titled `Open-source program: <repository>` or apply at
https://qafind.si/open-source. Include:

- repository URL
- how Playwright runs in CI
- approximate pull requests per month
- what you want to learn (flakes, regressions, evidence)

## What we ask

- feedback on classifications and false blocks
- permission to publish aggregate numbers (never code or test names)
- a named case study only with written approval

## Rules

- No spam. One issue or application per project.
- No access to private repositories for the free program.
- Do not run QAFind against systems you do not own or have permission to test.
