# Contributing

Thanks for helping improve AirlockQA.

## Development

```bash
bun install
bun test
bun run build
```

Use Bun for tests and scripts. Keep changes focused; add a test for behavior changes.

## Pull requests

- Describe the user-visible change and the test that proves it.
- Do not commit secrets, real customer data, or generated artifacts.
- For features that execute browser code, add or update the request-policy tests.
- Sign-off is not required, but keep commit messages clear.

## Reporting security issues

See [SECURITY.md](SECURITY.md); do not open a public issue for a vulnerability.
